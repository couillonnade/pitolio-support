# Books and flights

**iPad only.**

A **book** holds successive flights and the templates used for new flights. A **flight** holds one to four pages and can own one Fuel Timer. All pages of that flight share its timer.

## Create and open

- **Home → New book**: choose its name and one/two starting templates.
- **Book → New flight**: create fresh pages from that book's defaults.
- Tap the book card to open its newest visible flight on page one.
- **Book actions (… ) → Book name & templates**: rename the book or change templates for future flights.

**Settings → Default pages for new books** affects books created afterward. Existing books keep their own choices. Changes save when you go Back.

## Switch and rename

The centered title shows **Flight 3 / 5** with Previous/Next arrows. These switch directly between flights. Tap the title to open **Flights**, then select a flight. **Rename** on the current flight's row changes its title.

**New flight** stays on the right of the title bar.

## Pages toolbar

| Control | Action |
| --- | --- |
| Page number / pair | Select a page or landscape spread |
| + | Add a page using a chosen template, up to four |
| Bin | Choose **This page** or **This flight**, then confirm Trash |
| Template/background icon | Choose a page and apply a template to an empty page |
| Share icon | Export this flight's pages as a PDF |

Portrait/narrow windows show one page. Wide landscape windows show pages 1–2 or 3–4; an unpaired page fills the width. Redundant page tabs disappear when both pages are already visible. Tool labels become icons for three/four pages or a compact window; long-press an icon for its tooltip.

## Delete and restore

Use the bin for a page/flight, or **Home → book actions → Delete book**. These move content to **Settings → Trash**, where it can be restored. A restored flight is again visible in its book.

The active timer's owner is protected from deletion. Finish or cancel that timer first. Deleting a saved timer log is a separate action in [timer history](fuel-timer.md#saved-timer-flights).
