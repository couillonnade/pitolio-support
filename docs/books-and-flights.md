# Books and flight pages

Pitolio 1.2.0 · Updated 27 October 2026

**iPad only.**

A **book** contains successive flights. Each flight has one to four **flight pages**. A **flight** is the process that records OUT/OFF/ON/IN and includes the **fuel timer**. Its saved record is a **flight log**, listed in **Flight history**. Flight pages can also be used without starting a flight.

## Create and open

- **Home → New book**: choose its name and one or two starting page templates.
- **Book → New flight pages**: create fresh pages from that book’s defaults.
- Tap a book card to open its newest visible flight’s first page.
- **Book actions (… ) → Book name & templates**: rename the book or change templates for future flight pages.

**Settings → Default pages for new books** affects books created afterwards. Existing books keep their own choices. Changes save when you go Back.

## Switch and rename

The centered title shows **Flight 3 / 5** with Previous/Next arrows. These switch between flights in that book. Tap the title to open **Flights**, then select a flight. **Rename** on the current flight’s row changes its title.

**New flight pages** stays on the right of the title bar. **Flight history** is the separate list of saved flight logs.

## Pages toolbar

| Control | Action |
| --- | --- |
| Page number / pair | Select a page or landscape spread |
| + | Add a page using a chosen template, up to four |
| Bin | Choose **This page** or **Flight pages**, then confirm Trash |
| Template/background icon | Choose a page and apply a template to an empty page |
| Overlapping pages | Copy this flight, using each field’s Copy content setting |
| Share icon | Export this flight’s pages as a PDF |

Portrait and narrow windows show one page. Wide landscape windows show pages 1–2 or 3–4; an unpaired page fills the width. Redundant page tabs disappear when both pages are visible. Compact toolbars retain tooltips and accessibility labels.

Each of OUT, OFF, ON, IN, Block and Flight can appear only once across a flight’s one to four pages. Template, page and restore choices report conflicts, such as **“OUT is already on page 1.”** Existing layouts with repeated time fields remain readable; their values stay shared.

## Copy a flight

**Copy this flight** creates a new flight in the same book with all its pages in order. Fields whose template has **Copy content** enabled retain their typed values and handwriting inside those fields. Other fields start blank. The copy has its own date and no association with the original flight’s timer or log. PDF backgrounds stay available with blank annotations. Change the reusable template’s Copy content settings for future pages; existing pages keep their saved settings.

## Open the associated flight log

The completed-flight summary has a visible **Open Flight Log** button and **Delete log** icon beside it. Open shows that flight’s saved log even if another flight is active. Delete removes the logs associated with these pages after confirmation; pages, handwriting and recorded times remain.

In Flight history and a flight log, a flight-pages icon opens the associated pages. Flights without pages have no icon. An unavailable or trashed set of pages has a disabled icon with an explanation.

## Delete and restore

The pages bin, or **Home → Book actions → Delete book**, moves content to **Settings → Trash**. Restore it there. **Empty Trash** permanently removes trashed books, flights and pages after confirmation; export an editable backup first if you need to keep them. Backgrounds still used by saved pages are retained. If saving fails, the Trash is kept for retry. The book and pages associated with an active flight are protected; end or cancel the flight first.

Deleting from **Flight history** offers **Delete log only** by default, or **Delete log and flight pages**. The explanation gives the number of associated pages. The second choice removes the selected log and moves all its flight pages to Trash. Other logs remain. Restoring pages does not recreate a deleted log.
